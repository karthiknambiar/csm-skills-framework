- [ ] **Step 6: Download and verify every checksum and installer URL**

```powershell
$releaseAudit = Join-Path ([System.IO.Path]::GetTempPath()) ("csaf-release-audit-" + [guid]::NewGuid())
New-Item -ItemType Directory -Path $releaseAudit | Out-Null
gh release download v0.1.0 --dir $releaseAudit
$expected = @{}
Get-Content (Join-Path $releaseAudit 'SHA256SUMS') | ForEach-Object {
  if ($_ -notmatch '^([0-9a-f]{64})  ([^/\\]+)$') { throw 'invalid SHA256SUMS line' }
  $expected[$Matches[2]] = $Matches[1]
}
$actualFiles = Get-ChildItem -LiteralPath $releaseAudit -File | Where-Object Name -ne 'SHA256SUMS'
if (Compare-Object ($expected.Keys | Sort-Object) ($actualFiles.Name | Sort-Object)) { throw 'asset set does not match SHA256SUMS' }
foreach ($file in $actualFiles) {
  $digest = (Get-FileHash -LiteralPath $file.FullName -Algorithm SHA256).Hash.ToLowerInvariant()
  if ($digest -ne $expected[$file.Name]) { throw "checksum mismatch: $($file.Name)" }
}
if ((Invoke-WebRequest -UseBasicParsing 'https://github.com/karthiknambiar/csm-skills-framework/releases/download/v0.1.0/install.ps1').StatusCode -ne 200) { throw 'install.ps1 unavailable' }
if ((Invoke-WebRequest -UseBasicParsing 'https://github.com/karthiknambiar/csm-skills-framework/releases/download/v0.1.0/install.sh').StatusCode -ne 200) { throw 'install.sh unavailable' }
```

Expected: all published digests match and both README installer URLs return HTTP 200. Delete only the exact generated audit directory after confirming its resolved path is below the system temporary directory.
